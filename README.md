# Portafolio personal — Criptografía

Sitio de una sola página desarrollado únicamente con HTML, CSS y JavaScript. El contenido actual es demostrativo y está preparado para reemplazarse con información personal.

## Personalización rápida

- Cambia el nombre, biografía, fechas, escuelas, pasatiempos y datos de contacto en `index.html`.
- Reemplaza el bloque circular de iniciales por una imagen personal dentro de `.portrait-ring`.
- Sustituye `assets/cv-andrea-rodriguez.txt` por el CV real (idealmente PDF) y actualiza el enlace si cambia el nombre.
- Sustituye `assets/llave-publica-andrea.asc` por la llave pública real.
- Actualiza los enlaces de LinkedIn, GitHub e Instagram en la sección de contacto.

## Vista local

Puedes abrir `index.html` directamente o servir la carpeta con cualquier servidor web estático.
